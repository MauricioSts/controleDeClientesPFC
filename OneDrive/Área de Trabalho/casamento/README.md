# Convite de Casamento Digital

Convite de casamento digital elegante e delicado, desenvolvido em React com Tailwind CSS e Framer Motion.

## 🚀 Tecnologias

- **React 18** - Biblioteca JavaScript para interfaces
- **Vite** - Build tool moderna e rápida
- **Tailwind CSS** - Framework CSS utility-first
- **Framer Motion** - Biblioteca de animações para React

## 📦 Instalação

1. Instale as dependências:
```bash
npm install
```

2. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

3. Acesse no navegador:
```
http://localhost:5173
```

## 🏗️ Build para Produção

Para gerar uma versão otimizada para produção:

```bash
npm run build
```

Os arquivos serão gerados na pasta `dist/`.

## 📱 Características

- Design responsivo otimizado para celular
- Animações suaves com Framer Motion
- Decorações florais em SVG
- Ícones interativos com feedback visual
- Tipografia elegante (Great Vibes para nomes, Playfair Display para títulos)
- Cores românticas (rosa, bege, cinza)

## 🎨 Personalização

Para personalizar o convite, edite o arquivo `src/components/WeddingInvitation.jsx`:

- Nomes do casal
- Data e horário
- Textos do convite
- Cores (em `tailwind.config.js`)
